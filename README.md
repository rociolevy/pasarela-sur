# Pasarela Sur

Feria de diseño de moda de autor en Buenos Aires. Primera entrega del proyecto con Bootstrap 5.

## Archivos

- `index.html`: página principal
- `css/estilos.css`: estilos propios (fuentes de Google Fonts con `@import`)
- `js/codigo.js`: carga las tarjetas de diseñadores con `fetch` y valida el formulario del modal
- `js/disenadores.json`: datos de los diseñadores
